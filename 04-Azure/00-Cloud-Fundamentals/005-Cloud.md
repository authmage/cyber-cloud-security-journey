
# ☁️ Cloud (2006)

Cloud refers to a collection of remote computing resources (servers, storage, databases, networking, and software) that we can access over a network (usually the internet).

- A server or computing resource that can be accessed remotely.
- Renting servers and other computing resources using virtualization.
- Technologies introduced and used in cloud environments include Docker, Kubernetes, microservices, Infrastructure as Code (IaC), CI/CD, and serverless computing.

Instead of storing everything on your personal computer or maintaining your own physical servers, you can use computing resources provided by companies such as AWS, Microsoft Azure, and Google Cloud.

---

## ☁️ Cloud Computing

Cloud computing is the on-demand delivery of computing services (such as servers, storage, databases, networking, and software) from cloud data centers on a pay-as-you-go basis.

- **Pay as you go:** You pay for what you use, just like an electricity bill.

### ✅ Benefits of Cloud Computing

- No upfront payment.
- Highly scalable and elastic.
- Can be accessed from anywhere in the world.

---

## 🛒 Example of Cloud Computing

Imagine an organization launches a shopping website.

- On normal days, 1,000 users visit the website.
- During a festival sale, 100,000 users may visit the website.

With suitable cloud services, the organization can increase computing resources to handle the additional traffic and reduce them when demand decreases.

---

## ❓ Why Do We Need Cloud Computing?

Before cloud computing became widely available, organizations faced several challenges.

| Previous Problems | How Cloud Computing Helps |
|---|---|
| Purchasing expensive physical servers. | Rent computing resources. |
| High hardware maintenance costs. | Cloud providers manage the underlying infrastructure. |
| Limited storage capacity. | Increase storage when required. |
| Difficult to scale resources. | Scale resources up or down. |
| Time required to set up servers. | Provision resources quickly. |
| High initial investment. | Pay for resources based on usage and the pricing model. |
