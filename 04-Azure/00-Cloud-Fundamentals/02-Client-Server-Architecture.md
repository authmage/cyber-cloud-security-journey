
# 🌐 Client-Server Architecture

**Client-Server Architecture** is a model in which two main components, called a **Client** and a **Server**, communicate with each other over a network to exchange information and provide services.

## 🔹 Client and Server

- **Client:** A hardware device or software application that requests data, resources, or services.

  **Examples:** Laptop, mobile phone, web browser.

- **Server:** A hardware device or software system that receives requests, processes them, and sends back responses.

  **Examples:** Web server, database server.

## 🔄 How Client-Server Architecture Works

- The client sends a request to the server.
- The server provides data or services in response.
- It works on the **Request-Response Model**.
- **Client – Active Open:** Initiates a connection and can send requests and receive responses.
- **Server – Passive Open:** Waits for incoming connection requests and responds to client requests.
- Makes it easier to administer and share resources.

---

## 🏢 Traditional Servers vs. Cloud Servers

In traditional client-server architecture, organizations maintain physical servers in their own offices or data centers.

In cloud computing, companies can use servers hosted by cloud providers instead of purchasing and maintaining their own physical servers.

---

## 🔗 How Does a Client Communicate with a Server?

A client communicates with a server through a network using communication protocols such as **HTTP** and **HTTPS**.

---

## 🖥️ Difference Between a Server and a Computer/PC

| Computer / PC | Server |
|---|---|
| Designed for individual use. | Designed to provide services to multiple clients. |
| Usually switched off when not needed. | Often designed to run 24/7. |
| Usually has limited storage and resources (RAM and CPU capacity is low). | Can have large storage and higher computing resources (RAM and CPU capacity is high). |
| Generally runs desktop operating systems. | Can run server operating systems. |

---

## ❓ Can a Normal PC Work as a Server?

Yes, a normal PC can work as a server if we install and configure the necessary server software.

**Example: Windows 11 Laptop**

- If you use it to browse the internet, it acts as a **Client**.
- If you configure it to host a website and allow other computers to access it, it acts as a **Web Server**.
