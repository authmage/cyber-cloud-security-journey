## 👋 About This Repository

Welcome to my **Cybersecurity & Cloud Security learning repository!**

This repository documents my learning journey as I build a strong foundation in operating systems, networking, cybersecurity, identity and access management, and cloud security.

My goal is to understand how systems work, how security threats are detected, and how identities, networks, endpoints, and cloud environments can be protected.

📚 **Learn → Practice → Document → Improve**

## 🎯 Learning Goals

- 🖥️ Understand Windows and Linux operating systems.
- 🌐 Build strong networking fundamentals.
- 🛡️ Learn security operations and threat detection (SOC).
- 🔑 Explore Identity and Access Management (IAM).
- ☁️ Understand cloud computing and cloud security.
- 🔍 Practice security concepts through hands-on labs.
- 📝 Document concepts, commands, tools, and lessons learned.

## 📂 Topics Covered

| Topic | What I'm Learning |
