
# 💻 Virtualization

Virtualization is a technology that allows us to create multiple virtual computers (virtual machines) on a single physical computer or server.

---

## 🖥️ Virtual Machine (VM)

A Virtual Machine (VM) is a software-based computer that behaves like a physical computer.

**It has:**

- Virtual CPU
- Virtual RAM
- Virtual hard disk
- Virtual network card
- Operating System (OS)

---

## ⚙️ Hypervisor

A Hypervisor is a software or virtualization layer that creates, runs, and manages virtual machines.

**Its responsibilities include:**

- Creating virtual machines.
- Allocating CPU and RAM.
- Managing virtual storage and virtual networking.
- Keeping virtual machines isolated.

---

## 🔍 Types of Hypervisors

There are two types of hypervisors:

1. **Type 1:** Bare-Metal Hypervisor
2. **Type 2:** Hosted Hypervisor

---

### 1️⃣ Type 1 – Bare-Metal Hypervisor

- Runs directly on the physical hardware.
- Virtual machines can be created on the physical server.
- **Examples:** VMware ESXi, Microsoft Hyper-V, Xen.

**Used in:**

- Data centers
- Enterprise servers
- Cloud infrastructure
- Large organizations

---

### 2️⃣ Type 2 – Hosted Hypervisor

- Runs on an existing operating system (like normal software) on a physical laptop or PC.
- **Examples:** VMware Workstation, Oracle VirtualBox, Parallels Desktop.

**Used in:**

- Personal laptops
- Learning and training
- Software testing
- Cybersecurity labs
- Running different operating systems
