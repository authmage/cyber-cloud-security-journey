
# 🖥️ Hardware Components of a Firewall

## 1️⃣ Management Port
- A dedicated interface for administration and management services such as SSH, GUI, SNMP, DNS, and NTP.
- Used to manage and configure the firewall.

## 2️⃣ Console Port
- Used for initial configuration and troubleshooting.
- Provides direct access to the firewall through a console connection.
- Provides direct CLI access and helps reduce downtime.

## 3️⃣ HA Ports (High Availability Ports)
- Used for communication between two Palo Alto firewalls configured as a High Availability (HA) pair.
- Allows both firewalls to work together for redundancy.

## 4️⃣ Ethernet Interfaces
- Used as data ports for network traffic.

## 5️⃣ Power Supply
- Supplies power to the firewall appliance.

## 6️⃣ CPU (Central Processing Unit)
- Acts as the brain of the firewall.
- Processes firewall operations.
- Handles management and control functions.

## 7️⃣ RAM (Random Access Memory)
- Temporarily stores running processes and data.
- Helps maintain active sessions.
- Supports firewall operations.

## 8️⃣ Storage (SSD/HDD)
- Stores the firewall operating system and configuration.
- Stores logs and other system files.
- May also store software updates.
