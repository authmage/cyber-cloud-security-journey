
# 🛡️ Palo Alto Networks Products

Palo Alto Networks has three major product platforms:

1. **Strata** – Network Security
2. **Prisma** – Cloud Security and SASE
3. **Cortex** – AI-Driven Security Operations

---

# 1️⃣ STRATA – Network Security

- A major part of Strata is Next-Generation Firewall (NGFW).
- Protects networks using NGFWs and network security services.

## 🔥 PA-Series Firewalls (Physical Firewalls)

PA-Series refers to physical firewall appliances.

| Deployment | Firewall Series | Examples |
|---|---|---|
| Small Office | PA-400 Series | PA-410, PA-440, PA-450 |
| Branch Office | PA-1400 Series | PA-1410, PA-1420 |
| Enterprise | PA-3400 Series | PA-3410, PA-3420, PA-3430, PA-3440 |
| Data Center | PA-5400 Series, PA-7500 Series | — |

## 💻 VM-Series Firewalls (Virtualized Next-Generation Firewalls)

- Instead of running on a dedicated physical appliance, a VM-Series firewall runs as a virtual machine in a supported virtualized environment.
- VM-100, VM-300, VM-500

## 📦 CN-Series Firewalls

- Container firewalls 
- Designed to provide security for containerized environments.
- CN series for Kubernetes

## 📌 Other Products

- **PAN-OS**
- **Panorama**
- **GlobalProtect**
- **Cloud NGFW**
